# User Stories (v0.1)

I wrote these stories to describe what different users might want to do with the application. They are based on the current project idea and will be revised after user feedback.

| ID | User story | Related requirement |
| --- | --- | --- |
| US-01 | As a traveler, I want to browse crafts without creating an account, so I can quickly explore a place. | FR-01 |
| US-02 | As a visitor, I want to search by craft name or tag, so I can find something specific. | FR-02 |
| US-03 | As a contributor, I want to create an account, so I can share crafts I know about. | FR-03 |
| US-04 | As a contributor, I want to add a craft with photos and a description, so other people can learn about it. | FR-04, FR-05 |
| US-05 | As a craft enthusiast, I want to read about materials and production methods, so I can understand how an item is made. | FR-06, FR-07 |
| US-06 | As a contributor, I want to suggest a category when I cannot find a suitable one, so I can describe my craft properly. | FR-08 |
| US-07 | As a contributor, I want to add tags, so others can discover my craft through related keywords. | FR-09 |
| US-08 | As a traveler, I want to see crafts on a map, so I can discover crafts around a destination. | FR-10 |
| US-09 | As a contributor, I want to edit my own entries, so I can correct mistakes or update information. | FR-11 |

## Example Scenario

Someone visiting Texas searches for cowboy hats. They find a handmade hat entry with a photo, the materials used, and a short explanation of how it is made. They can also see its approximate location on a map. If a contributor wants to add another type of hat, they can use an existing category or suggest a new one.
