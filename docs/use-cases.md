# Use Cases v0.1

## UC-01: Search Crafts

**User:** Visitor

1. User opens the website.
2. User searches for a craft.
3. Website shows the results.
4. User clicks on a craft to see more information.

**If nothing is found:** Website shows a message.

## UC-02: Register

**User:** Visitor

1. User opens the register page.
2. User enters email and password.
3. User clicks Register.
4. Website creates the account.

**If there is a problem:** Website shows an error.

## UC-03: Add Craft

**User:** Registered user

1. User logs in.
2. User clicks Add Craft.
3. User enters craft name and description.
4. User uploads a photo.
5. User selects a category and location.
6. User saves the craft.

**If information is missing:** Website asks the user to fill it in.

## UC-04: Find Crafts on Map

**User:** Visitor

1. User opens the map.
2. Website shows crafts on the map.
3. User clicks on a craft.
4. Website shows information about it.

## UC-05: Suggest Category

**User:** Registered user

1. User wants to add a craft.
2. User cannot find the correct category.
3. User suggests a new category.
4. Website saves the suggestion.

The category approval process will be decided later.
