# Requirements (v0.1)

These are my initial requirements for the Local Craft Discovery Guide. I may update them after getting feedback from potential users.

## Functional Requirements

| ID | Requirement |
| --- | --- |
| FR-01 | Visitors can browse craft entries without logging in. |
| FR-02 | Visitors can search crafts by name, category, or tag. |
| FR-03 | Users can register and log in. |
| FR-04 | Logged-in users can add a craft with a name, description, and location. |
| FR-05 | Users can upload at least one photo of a craft. |
| FR-06 | Users can enter materials and how the craft is made. |
| FR-07 | Users can optionally add measurements such as weight (grams) and volume (liters). |
| FR-08 | Users can select an existing category or suggest a new one. |
| FR-09 | Users can add tags to their craft entries. |
| FR-10 | Visitors can see the approximate location of a craft on a map. |
| FR-11 | Users can edit or delete their own craft entries. |

## Non-Functional Requirements

| ID | Requirement |
| --- | --- |
| NFR-01 | The website should work on desktop and mobile browsers. |
| NFR-02 | Passwords must not be stored as plain text. |
| NFR-03 | Only the owner of a craft entry should be able to edit or delete it. |
| NFR-04 | The application should validate required fields and measurements. |
| NFR-05 | The interface should be simple enough for first-time visitors to use. |
| NFR-06 | Exact private addresses should not be displayed automatically. |

## Questions to Decide Later

- Do we need to approve new categories before they appear?
- Should a craft location represent the maker's workshop or the region where the craft is traditionally made?
- Should ratings and comments be part of the first release or added later?

These requirements are a starting point, not the final list.
